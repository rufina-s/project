# Секреты Темнолесья — анализ игровой экономики

## О проекте

Учебный аналитический проект, посвящённый исследованию поведения пользователей и игровой экономики на основе данных онлайн-игры «Секреты Темнолесья»

## Цель проекта

Провести анализ игровых покупок, изучить поведение пользователей, выявить закономерности покупательской активности и особенности внутриигровых расходов

## Инструменты

- **MS SQL** - обработка и анализ данных с помощью SQL-запросов
- **Microsoft PowerPoint** - визуализация и презентация результатов

## Основные направления анализа

- Исследование структуры и качества данных
- Анализ игровой активности и покупательского поведения
- Определение наиболее популярных игровых предметов
- Сравнение покупательской активности по игровым расам, классам и странам
- Анализ распределения расходов и выявление аномальных значений
- Исследование динамики покупок

## Материалы проекта

- `Описание проекта.pdf` - постановка задачи и описание данных
- `Temnolesye_MS_SQL.sql` - SQL-запросы и аналитические расчёты
- `Презентация.pptx` - визуализация результатов исследования
- `Выводы.pdf` - результаты анализа и рекомендации

## Результат

Проведён анализ игровой экономики и покупательского поведения пользователей. Выявлены особенности распределения внутриигровых расходов, определены наиболее популярные игровые предметы, исследованы различия в покупательской активности между расами, классами и странами. Подготовлены аналитические выводы и рекомендации для маркетингового отдела.
