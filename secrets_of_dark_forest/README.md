\# Секреты Темнолесья — анализ игровой экономики



\## О проекте



Учебный аналитический проект, посвящённый исследованию поведения пользователей и игровой экономики на основе данных онлайн-игры «Секреты Темнолесья».



\## Цель проекта



Провести комплексный анализ игровых покупок, изучить поведение пользователей, выявить закономерности потребительской активности и определить факторы, влияющие на внутриигровые расходы.



\## Инструменты



\- MS SQL

\- SQL-запросы для обработки и анализа данных

\- Microsoft PowerPoint — визуализация и презентация результатов



\## Основные направления анализа



\- Исследование структуры и качества данных.

\- Анализ игровой активности и покупательского поведения.

\- Определение наиболее популярных игровых предметов.

\- Сравнение покупательской активности по игровым расам.

\- Анализ распределения расходов и выявление аномальных значений.

\- Исследование динамики покупок.

\- Сегментация пользователей по объёму покупок.



\## Материалы проекта



\- SQL-файл — запросы и аналитические расчёты.

\- Презентация PowerPoint — визуализация результатов исследования.

\- Описание проекта — постановка задачи и описание исследования.

\- Выводы — результаты анализа и рекомендации.



\## Результат



Проведён комплексный анализ игровой экономики, выявлены особенности покупательского поведения пользователей, определены наиболее популярные игровые предметы и сегменты пользователей с различным уровнем расходов.
