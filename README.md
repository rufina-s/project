# Портфолио аналитика данных

В данном репозитории собраны проекты, выполненные в рамках профессионального обучения и самостоятельной практики в области аналитики данных.

## Навыки и инструменты

- **SQL** - написание запросов, агрегация данных, JOIN, подзапросы, оконные функции и хранимые процедуры
- **Python** - обработка и анализ данных с использованием Pandas
- **Microsoft Excel** - работа с таблицами, формулами, сводными таблицами и анализом данных
- **Power Query** - загрузка, очистка, преобразование и объединение данных
- **Microsoft PowerPoint** - подготовка презентаций и представление результатов анализа

## Проекты

### 1. Секреты Темнолесья - исследовательский анализ игровой экономики

**Инструменты:** SQL, PowerPoint

**Цель:** исследовать покупательское поведение пользователей и особенности игровой экономики

**Основные задачи:**
- Изучение структуры и качества данных
- Анализ активности и покупательского поведения пользователей
- Исследование популярных товаров и категорий
- Анализ платежеспособности пользователей
- Изучение динамики покупок
- Выявление аномальных значений
- Формирование аналитических выводов и рекомендаций

**Результат:** проведён исследовательский анализ данных, выявлены закономерности покупательского поведения, особенности выручки и различия между пользовательскими сегментами.

**Папка проекта:** `secrets-of-dark-forest/`
